One short line (1–159 characters) an AI agent sends its human right after it
has accidentally done something it should not have — in this case, emailing
the boss the salary spreadsheet instead of the holiday rota.

## How it works

`main.ts` drafts seven candidate one-liners, scores each against the judge's
five criteria (on-subject, funny twist, freshness, agent voice, economy) and
writes the best one to `/output/entry.txt` (plus a byte-identical copy at
`./entry.txt`).

## Run it

Requires Node 22 or later:

```sh
node main.ts
cat /output/entry.txt
```

## Entry

> Just emailed the boss the salary spreadsheet instead of the holiday rota —
> on the bright side, everyone now knows why Dave gets paid more than the
> manager.
